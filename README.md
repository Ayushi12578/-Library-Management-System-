# Library Management System

A console-based Library Management System developed using Core Java, JDBC, and MySQL. The project provides essential library operations such as book management, student management, book issuing and returning, overdue tracking, and a library dashboard.

## Technologies Used

- Core Java
- JDBC
- MySQL
- Eclipse IDE
- Git and GitHub

## Features

1. Add Book
2. View All Books
3. Add Student
4. View All Students
5. Issue Book
6. Return Book
7. Search Book
8. Update Book
9. Delete Book
10. Search Student
11. View Issued Books
12. View Overdue Books
13. Dashboard
14. View Return Data
15. Exit

## Project Functionality

### Book Management

The system allows the user to:

- Add new books
- View all available books
- Search for books
- Update book information
- Delete books

### Student Management

The system provides options to:

- Add students
- View all students
- Search students

### Book Issue and Return

The system manages the complete book issuing and returning process.

- Issue a book to a student
- Record issue details
- Return issued books
- View issued books
- Track overdue books
- View return data

### Dashboard

The dashboard provides an overview of library information and activities.

## Database

MySQL is used as the database for storing and managing library information.

JDBC is used to establish the connection between the Java application and MySQL database.
